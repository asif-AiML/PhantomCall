# 👻 PhantomCall

PhantomCall is a stealth utility application built with React Native and Expo. It provides a flawless, simulated incoming call to help users gracefully exit awkward or uncomfortable social situations. 

Unlike other utilities, PhantomCall is designed with absolute privacy in mind: zero ads, zero tracking, and 100% offline operation.

## ✨ Features

* **Stealth Timer:** Set a delayed countdown (e.g., 10 seconds, 1 minute) so you can put your phone away before the call triggers.
* **Custom Caller ID:** Personalize the incoming caller's name and phone number to make the escape completely believable.
* **Custom Media:** Upload a specific caller avatar/image and select a custom audio ringtone from your device.
* **Native-Feeling UI:** Utilizes smooth animations, a polished onboarding flow, and a dark-mode stealth aesthetic that mimics a native Android telecom interface.
* **Privacy First:** The app requires absolutely no internet connection to function. Your data never leaves your device.
